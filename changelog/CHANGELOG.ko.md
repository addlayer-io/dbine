# 변경 사항

## [1.1.0] - 2026-10-21

### 새로운 기능
- **라이선스:** DBine은 이제 Apache License 2.0으로 배포됩니다(1.0.0까지는 MIT). 재배포 시 NOTICE 파일이 함께 제공되며, 이 라이선스는 DBine과 AddLayer의 이름이나 로고 사용을 허용하지 않습니다.
- **클라우드 동기화 상태를 한눈에:** 상태 표시줄에 초록색 점과 함께 **동기화됨**, 변경 사항이 업로드를 기다리는 동안에는 호박색으로 **업로드 대기**, 오류가 나면 빨간색이 표시됩니다. 마우스를 올리면 마지막 동기화 시각이 보이고, 클릭하면 동기화 설정이 열립니다.
- **연결 문자열 복사:** 연결을 마우스 오른쪽 버튼으로 클릭하거나(또는 연결 양식의 버튼을 사용해) **연결 문자열 복사…** 를 선택하면 해당 엔진에 맞는 URI, ADO.NET, JDBC, SQLAlchemy, ODBC, libpq, Node.js, Go 형식의 연결 문자열을 모든 데이터베이스에 대해 TLS 및 로그인 설정과 함께 얻을 수 있습니다. 비밀번호는 포함되지 않으며(`${DB_PASSWORD}` 자리 표시자) **비밀번호 포함** 을 켠 경우에만 복사할 때 가져오고, 1분 뒤에도 클립보드에 남아 있으면 지워집니다.
- 예약 작업에 **메시지 보내기** 단계가 추가되었습니다. 실행 결과를 Microsoft Teams, Slack, Telegram 또는 ntfy에 게시할 수 있으며, 작업 변수(`{results}`는 각 단계가 수행한 내용을 나열합니다), 이메일 단계와 같은 **조건…**, **테스트** 버튼을 지원합니다. 웹후크 URL과 토큰은 작업이 아닌 키체인에 저장되며, 메시지는 해당 서비스 자체 서버로만 HTTPS를 통해 전송됩니다.

### 수정
- **SSH 터널, 보안:** SSH 라이브러리를 업데이트하여 두 가지 권고 사항(SSH 에이전트를 통한 서비스 거부 CVE-2026-111061 및 CVE-2026-111062)을 수정했습니다.
- **TLS, 보안:** DBine과 33개 드라이버의 TLS 라이브러리와 인증서 검사를 업데이트했습니다(RUSTSEC-2026-0346~0349 및 0381~0383). 이제 더 이상 신뢰하지 않는 인증 기관의 인증서는 거부됩니다. 업데이트된 드라이버는 자동으로 다운로드됩니다.
- **내장 AI 엔진:** 엔진 압축을 풀 때 파일의 읽기, 쓰기, 실행 권한만 유지됩니다.
- **예약 작업, 보안:** `{results}`와 `{alerts}`는 이제 메일과 메시지의 텍스트만 채웁니다. 스크립트의 SQL, 파일이나 폴더 이름, 주소, 첨부 파일 경로에는 더 이상 적용되지 않으므로, 조작된 데이터를 그대로 보여 주는 데이터베이스 오류가 SQL이나 경로로 바뀔 수 없습니다.
- **예약 작업 메시지:** 메시지나 메일의 `{results}`와 `{alerts}`가 항상 스페인어로 나오지 않고 DBine의 인터페이스 언어로 표시됩니다. DBine을 닫은 채 작업이 실행될 때도 마찬가지입니다.
- **노트북, 큰 DataFrame SQL 결과:** **고급 내보내기… › 모두** 가 표시된 행뿐 아니라 전체 결과를 기록합니다. 셀의 SQL은 마지막 실행에서 읽은 DataFrame을 대상으로 DuckDB에서 다시 실행되며, 파일을 다시 읽거나 소스를 다시 쿼리하지 않습니다. 차트는 처음부터 전체 결과로 계산되며 끌 수도 있습니다. 결과가 잘린 경우 정렬과 **모두 복사** 가 불러온 행에만 적용된다는 안내도 그리드에 표시됩니다.

## [1.0.0] - 2026-10-19

### 새로운 기능
- **라이트 테마:** 라이트 테마와 운영 체제가 바뀔 때 함께 따라가는 **시스템과 동일** 옵션(기본값)이 추가되었습니다. Cmd/Ctrl + "+", "−", "0" 또는 마우스 휠로 인터페이스를 확대/축소할 수 있고, 편집기와 결과 그리드의 글꼴 크기를 따로 지정할 수 있습니다(**설정 › 일반**).
- **Vim 모드와 사용자 지정 단축키:** SQL 편집기용 Vim 모드(설정 › 일반)를 지원하며, 모든 키보드 단축키를 **설정 › 키보드 단축키**에서 변경할 수 있습니다. 검색, 초기화, 충돌 경고도 제공합니다.
- **편집기 분할:** 편집기 그룹을 최대 3개까지 나란히 또는 위아래로 배치할 수 있습니다(탭 메뉴, 탭 표시줄 버튼 또는 Cmd/Ctrl+\). 탭을 그룹 사이로 끌어 놓거나 그룹의 오른쪽 또는 아래쪽 절반으로 끌어 놓아 분할할 수 있습니다. 레이아웃은 다시 시작해도 복원됩니다.
- **관리형 데이터베이스용 클라우드 로그인:** Amazon RDS와 Aurora, Google Cloud SQL과 AlloyDB, Azure Database에 대한 PostgreSQL 및 MySQL 연결에서 **AWS IAM**, **Google Cloud IAM**, **Microsoft Entra ID**로 로그인할 수 있습니다. DBine은 연결할 때마다 AWS 프로필(SSO 포함), gcloud 또는 az에서 새 토큰을 만들므로, 15분이면 만료되는 토큰을 붙여 넣을 필요가 없고 **테스트**에서 어떤 ID로 로그인했는지 확인할 수 있습니다.
- **명령 또는 시크릿 관리자에서 가져오는 비밀번호:** 모든 엔진의 모든 시크릿 필드와 SSH 터널의 비밀번호 및 키 암호 구문은 명령, 1Password, HashiCorp Vault, AWS Secrets Manager, Azure Key Vault 또는 Google Secret Manager에서 값을 가져올 수 있습니다. 값은 연결할 때마다 가져와 메모리에만 보관하며, JSON 키 옵션과 길이만 보여 주는 필드별 테스트도 제공합니다. 가져오기나 복원한 백업에서 온 명령 또는 시크릿 관리자 설정은 이 컴퓨터에서 확인한 뒤에만 실행됩니다.
- **비밀번호 출처로 KeePass와 Zoho Vault 추가:** 모든 시크릿 필드(SSH 터널 포함)가 KeePass 데이터베이스(.kdbx, DBine이 직접 읽음, 마스터 비밀번호는 키체인에서 가져오며 연결할 때 또는 명령으로 요청, 키 파일은 선택 사항)의 항목이나 Zoho Vault 시크릿(모든 데이터 센터, 사용자의 컴퓨터에서 마스터 암호 구문으로 복호화)에서 값을 가져올 수 있고, 원하면 연결의 사용자도 같은 항목에서 가져옵니다.
- **비밀번호 출처로 Vault 데이터베이스 자격 증명, CyberArk, Delinea 추가:** 연결 비밀번호를 HashiCorp Vault의 데이터베이스 시크릿 엔진(연결용으로 자격 증명을 만들고, 열려 있는 동안 갱신하며, 닫으면 폐기함, Vault는 AppRole 로그인도 지원), CyberArk Conjur, CyberArk Central Credential Provider(클라이언트 인증서 사용), Delinea Secret Server에서 가져올 수 있습니다.
- **비밀번호 출처로 Bitwarden, Bitwarden Secrets Manager, AWS Parameter Store 추가:** 모든 시크릿 필드(SSH 터널 포함)가 bitwarden.com, bitwarden.eu 또는 자체 서버의 Bitwarden 항목(개인용 또는 조직용, 사용자의 컴퓨터에서 마스터 비밀번호로 복호화), Bitwarden Secrets Manager 시크릿(머신 계정의 액세스 토큰 사용), AWS Systems Manager 매개변수(SecureString, String 또는 StringList의 요소 하나)에서 값을 가져올 수 있습니다. 원하면 JSON 키를 지정하고 연결의 사용자도 같은 항목에서 가져옵니다.
- **자격 증명을 먼저 선택하고 시크릿 관리자 찾아보기:** 연결 양식에서 가장 먼저 **자격 증명**을 묻습니다. 비밀번호를 키체인에 보관하거나, 매번 묻거나, 명령줄 또는 시크릿 관리자에서 사용자와 비밀번호를 가져올 수 있으며(해당 필드가 대신 사용됨), **찾아보기** 버튼으로 관리자의 항목과 필드 이름을 나열해 참조를 직접 입력하는 대신 선택할 수 있습니다. 이름만 표시하며 값은 절대 표시하지 않습니다.
- **항목에서 사용자와 비밀번호 가져오기:** 자격 증명으로 KeePass, Bitwarden, 1Password, Zoho Vault, Delinea 또는 CyberArk CCP를 사용하면 사용자와 비밀번호가 모두 항목에서 오며, **고급 설정**에서 항목 자체 목록의 다른 필드를 고를 수 있습니다. 모든 출처는 로그인 정보를 먼저, 항목을 마지막에 묻고, 이를 입력하면 찾아보기를 사용할 수 있습니다.
- **Zoho Vault 계정, 한 번만 연결:** 안내형 **Zoho Vault 연결** 도우미가 Zoho 콘솔을 안내하고 데이터 센터를 찾아 마스터 암호 구문을 확인합니다. 이후에는 어떤 연결에서든 계정만 선택하면 됩니다. 계정은 이 컴퓨터에 보관되며 **설정 › 시크릿 관리자**에서 관리합니다.
- **모든 시크릿 관리자의 계정:** Bitwarden, Bitwarden Secrets Manager, HashiCorp Vault와 OpenBao, Delinea, CyberArk Conjur와 Central Credential Provider, 1Password, AWS, Azure Key Vault, Google Secret Manager, KeePass를 이제 **설정 › 시크릿 관리자**에서 안내형 도우미로 한 번만 연결하면 됩니다. 도우미는 각 값의 위치를 설명하고, 계정을 실시간으로 확인하며, 누가 로그인했는지 보여 줍니다. 이후에는 어떤 연결에서든 계정만 선택하면 되고, 자격 증명은 해당 관리자 자체 서버로만 전송됩니다.
- **선택할 수 있는 Azure 테넌트:** Azure Key Vault 계정 도우미가 Microsoft Entra 테넌트를 나열하며(직접 입력도 가능), 선택한 테넌트에 로그인하지 않은 경우 복사할 수 있는 `az login --tenant` 명령을 보여 줍니다.
- **DataFrame SQL 셀의 자동 완성:** 위쪽 셀이 테이블로 제안되며(아직 실행하지 않은 셀도 포함), `name.` 또는 별칭 뒤와 select 목록에서 해당 열이 제안됩니다. FROM과 JOIN 뒤에는 DuckDB의 파일 리더도 제안됩니다. 리더를 선택하면 커서가 따옴표 사이에 놓이고, **파일 선택…**으로 파일 대화 상자를 열 수 있습니다. 노트북이 새로 고쳐지는 동안 FROM 뒤의 테이블 목록이 저절로 닫히지도 않습니다.
- **지도 보기:** 지오메트리 열(PostGIS, MySQL, SQL Server, SQLite/SpatiaLite, DuckDB, MongoDB, Elasticsearch 등) 또는 위도/경도 열이 있는 결과를 지도에 표시할 수 있습니다. 지도는 내장된 오프라인 세계 지도 위에 이 컴퓨터에서 그려집니다. 상세한 온라인 지도 타일은 **설정 › 지도**에서 켤 수 있으며, 이 경우 제공업체는 보고 있는 영역은 알 수 있지만 데이터는 알 수 없습니다.
- **지도에서 Oracle 지원:** SDO_GEOMETRY 열이 이제 테이블 데이터와 직접 작성한 쿼리 모두에서 결과 지도에 표시됩니다(서버에서 SRID와 함께 WKT로 변환). 이 셀은 그리드에서 읽기 전용입니다.
- **데이터 파일 바로 열기:** SQLite, DuckDB, CSV, TSV, Parquet, JSON, Excel 파일을 더블 클릭하거나 "DBine으로 열기", 창에 끌어 놓기, **파일 › 파일 열기…**(Cmd/Ctrl+O)로 열 수 있습니다. 각 파일은 임시 연결로 열리며 **연결 저장**으로 보관할 수 있고, 데이터 파일은 처음 1,000행을 바로 보여 줍니다.
- **명령 팔레트:** Cmd/Ctrl+Shift+P로 모든 작업을 찾아 실행할 수 있으며, 현재 엔진이 지원하는 것만 표시됩니다. **이동…**(Cmd/Ctrl+P)으로 연결, 데이터베이스, 테이블, 뷰, 루틴, 저장된 쿼리, 열려 있는 탭으로 이동할 수 있습니다. 팔레트의 모든 작업에 고유한 단축키를 지정할 수도 있습니다.
- **관련 행으로 이동:** 테이블 데이터나 쿼리 결과에서 **참조된 행으로 이동**(또는 Cmd/Ctrl+클릭)을 선택하면 해당 외래 키로 필터링된 부모 테이블이 열리고, **이 행을 참조하는 행**을 선택하면 그 값으로 필터링된 각 자식 테이블이 열립니다(복합 키 포함). 외래 키가 있는 모든 엔진에서 사용할 수 있습니다.
- **SQL 노트북:** **파일 › 새 노트북**으로 노트북을 엽니다. 어떤 연결에서든 실행되는 SQL 셀이 각각 결과와 차트를 아래에 보관하며, 설명을 위한 텍스트 셀도 사용할 수 있습니다. 표준 Jupyter `.ipynb`로 저장되어 GitHub, VS Code, Jupyter에서 표시되며 Azure Data Studio와 Jupyter `%%sql` 노트북에서도 열 수 있습니다. 파일에는 각 결과의 미리 보기(셀당 100행과 1MB, **설정 › 노트북**에서 변경)가 전체 행 수, 시간, 소요 시간과 함께 저장되며 연결 정보나 비밀번호는 저장되지 않습니다. 프로젝트 안에서는 켜지 않는 한 노트북이 결과 없이 저장됩니다. 어시스턴트는 행을 보지 않고도 결과를 설명하거나, 다음 셀 또는 큰 쿼리의 그룹화된 버전을 제안할 수 있습니다. HTML 또는 Markdown으로 내보낼 수 있습니다.
- **전체 결과에 대한 차트:** 차트는 그리드에 불러온 행만이 아니라 결과의 모든 행을 기준으로 계산됩니다. SQL 엔진에서는 그룹화를 서버에서 실행하고, 노트북의 DataFrame SQL 셀에서는 DuckDB가, 그 밖의 엔진에서는 DBine이 처리합니다.
- **더 많은 차트 종류:** 히스토그램, 히트맵, 상자 수염 그림(수염과 이상치 포함), 막대와 선 조합, KPI(전체 결과의 합계).
- **노트북 셀당 여러 차트:** 노트북 셀은 결과에 대한 차트를 둘 이상 표시할 수 있으며, 지도가 사용하는 소스도 기억합니다.
- **노트북 내보내기에 차트 포함:** HTML 또는 Markdown으로 내보낸 노트북에 차트가 이미지로 포함됩니다.
- **노트북에서 서로 다른 데이터베이스의 결과 조인:** 각 셀의 결과는 셀 이름(헤더에 표시되며 편집 가능)을 가진 DataFrame이 되고, **DataFrame SQL** 셀은 연결 없이 위쪽 DataFrame을 테이블로 보고 DuckDB의 SQL로 조회하고 조인합니다. 그래서 하나의 셀에서 PostgreSQL 결과를 SQL Server, MongoDB 결과와 조인할 수 있습니다. 파일을 쓰거나 네트워크에 접근할 수 없는 메모리 내 DuckDB 데이터베이스에서 실행되며 노트북을 닫으면 삭제됩니다. 각 소스의 행은 이 세션에서의 실행 결과 또는 해당 소스의 연결에서 읽기 전용으로 다시 실행한 쿼리에서 가져옵니다(DataFrame당 최대 1,000,000행, **설정 › 노트북**에서 변경).
- **예약된 보고서로서의 노트북:** 예약된 작업은 DBine을 닫은 상태에서 노트북을 실행하고(**노트북 실행**), 실행된 사본을 저장하여 HTML 또는 Markdown으로 내보낼 수 있으며, 다음 **메일 보내기** 단계에서 이를 첨부하거나 HTML 내보내기를 메일 본문으로 보낼 수 있습니다. 무인 실행 중에는 아무것도 묻지 않습니다. 해당 노트북에서 **항상 허용**한 파일만 읽고, 확인이 필요한 환경에서는 단계가 명시적으로 허용한 경우에만 실행하며, 데이터를 변경하는 셀은 작업의 승인에 포함됩니다. 예약된 내보내기에는 표가 포함되며, 차트는 앱에서 내보낼 때 포함됩니다.
- **DataFrame SQL 셀의 로컬 파일:** DataFrame SQL 셀은 컴퓨터의 CSV, Parquet, JSON 또는 NDJSON과 Excel 파일을 `read_csv`, `read_parquet`, `read_json`, `read_xlsx`로 읽을 수 있습니다(`data/*.csv` 같은 패턴과 파일 목록 포함). 지리 파일(GeoJSON, 보조 파일이 있는 Shapefile, GeoPackage, KML, GPX, FlatGeobuf)은 `st_read`로, SQLite 및 DuckDB 데이터베이스 파일의 테이블은 `sqlite_scan`과 `read_duckdb`로 읽습니다. 각각은 DataFrame이 되어 어떤 엔진의 셀 결과와도 조인할 수 있으며, 지오메트리는 `ST_Contains` 같은 공간 함수로 계속 사용할 수 있고 지도에도 표시됩니다. 파일은 읽기만 하고 쓰지 않습니다. 파일을 처음 읽기 전에 노트북이 묻습니다. 이번 실행에만 허용, 이 컴퓨터에서 이 노트북에 항상 허용(패턴은 새 파일도 포함), 또는 거부 중에서 선택할 수 있습니다. 자격 증명, 키, 셸 기록, 시스템 파일은 절대 읽지 않습니다. 지난 실행 이후 파일 내용이 바뀐 경우 결과에 그 사실이 표시됩니다. 설정 › 노트북에는 각 노트북이 읽을 수 있는 파일이 나열되며 삭제할 수 있습니다. 같은 리더로 웹(`https://`)과 Amazon S3, Google Cloud Storage, Azure Blob Storage(`s3://`, `gs://`, `az://`, `abfss://`, `s3://bucket/2026/*.parquet` 같은 패턴 포함)의 파일도 읽을 수 있으며, 승인 방식은 같고 서버가 먼저 표시됩니다. DBine이 직접 파일을 읽은 뒤 삭제되는 비공개 임시 폴더에 다운로드하며, 이 컴퓨터의 AWS, Google Cloud 또는 Azure 로그인을 사용합니다(AWS 프로필은 설정 › 노트북에서 선택 가능). 로컬 또는 사설 네트워크 주소에는 접근하지 않고, 다른 서버로의 리디렉션을 따르지 않으며, URL에 포함된 자격 증명도 받아들이지 않습니다. 다른 프로그램에서 열려 있는 GeoPackage에는 이제 `-wal`에 남아 있는 변경 사항도 포함됩니다.
- **노트북을 Python 노트북으로 내보내기:** **내보내기 › Python 노트북(.ipynb)**은 원본을 재현하는 Jupyter 노트북을 작성합니다. 연결마다 SQLAlchemy 엔진(또는 pymongo, redis처럼 엔진 고유의 Python 클라이언트)을 만들고, 각 쿼리 셀은 셀 이름의 pandas DataFrame으로 읽으며, DataFrame SQL 셀은 그 DataFrame 위에서 DuckDB로 실행하고, 텍스트 셀은 Markdown이 됩니다. 비밀번호와 토큰은 절대 내보내지 않습니다. 코드는 환경 변수에서 읽으며, 첫 번째 셀에 환경 변수와 설치할 패키지가 나열됩니다. 미리 보기를 포함하도록 선택하지 않으면 결과는 제외됩니다.
- **노트북에서 DataFrame을 테이블에 쓰기:** **쓰기 셀**(아무 셀 아래에서 **테이블에 쓰기…**로 추가)은 셀의 전체 결과를 SQL Server, PostgreSQL, MySQL, MariaDB, Oracle, SQLite, DuckDB, MongoDB 등의 테이블에 씁니다. 삽입, 키 기준 업데이트, 삽입 또는 업데이트, 테이블 내용 교체를 선택할 수 있으며, 열 매핑과 미리 보기가 있고 원하면 새 테이블도 만들 수 있습니다. 쓰기는 매번 먼저 확인하며 대상, 방식, 행 수를 보여 줍니다(운영 환경 연결에서는 테이블 이름을 입력해야 함). 트랜잭션을 지원하는 엔진에서는 하나의 트랜잭션으로 실행되며, 읽기 전용 연결에는 절대 쓰지 않습니다. 예약된 작업에서는 단계가 해당 셀, 테이블, 모드를 허용한 경우에만 쓰기 셀이 실행됩니다.
- **노트북 매개변수:** 노트북은 매개변수(텍스트, 숫자, 날짜, 날짜와 시간, 불리언 또는 고정 목록, 기본값 포함)를 정의할 수 있으며, 셀에서 `{{name}}`으로 사용합니다. 실행할 때 빠진 값을 묻고, 각 값은 데이터로 데이터베이스에 전달되며(드라이버가 바인딩하거나 엔진 자체 규칙에 따라 따옴표 처리), 모든 결과에는 그 결과를 만든 값이 표시됩니다.
- **5개 언어 추가:** DBine과 모바일 앱이 스페인어, 영어, 포르투갈어, 프랑스어, 이탈리아어에 더해 독일어, 러시아어, 중국어 간체, 일본어, 한국어를 지원합니다. 언어는 시스템 언어를 따르며 사용 중인 언어만 불러옵니다.

### 개선
- **macOS 서명:** macOS 앱이 Apple Developer ID로 서명되고 Apple의 공증을 받았으므로 "개발자를 확인할 수 없음" 경고나 터미널 명령 없이 열립니다. 서명된 버전을 처음 열면 DBine이 키체인의 키를 사용해도 되는지 macOS가 한 번 묻습니다. **항상 허용**을 선택하세요.
- **클라우드 로그인은 인스턴스의 인증서만 신뢰:** AWS IAM, Google Cloud IAM, Microsoft Entra로 로그인하는 연결과 인스턴스의 CA 파일을 사용하는 Cloud SQL 및 AlloyDB 연결은 이제 토큰이나 비밀번호를 보내기 전에 임의의 공개 인증서가 아니라 해당 CA(또는 Amazon의 RDS 번들)만 허용합니다. **서버 인증서 신뢰**가 켜져 있을 때 비밀번호를 평문으로 요구하는 서버는 이제 비밀번호를 받지 못하고 연결에 실패합니다.
- **Windows 서명:** Windows 설치 프로그램과 앱이 코드 서명 인증서로 서명되었으므로 Windows가 "알 수 없는 게시자" 대신 DBine의 게시자를 표시합니다.

### 수정
- **서버 모니터:** 수치, 표, 설명이 모든 엔진에서 번역되어, 일부 레이블이 스페인어로 표시되던 문제가 해결되었습니다.
- **AI 어시스턴트와 최적화 도구:** 모델에 전달하는 지시문이 인터페이스 언어로 작성되므로, 로컬 모델이 스페인어가 아니라 해당 언어로 답변합니다. 모델에 무엇을 보냈는지 알려 주는 줄도 번역되었습니다.
