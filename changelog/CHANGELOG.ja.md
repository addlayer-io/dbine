# 変更履歴

## [1.5.0] - 2026-11-11

### 新機能
- **スキーマを比較の AI：** 名前が変更されたように見える列とテーブルが示され、削除して追加する代わりに、名前を変更してデータを保持できます。**AI で名前変更を検索**は、名前が似ていないものを見つけます。同期ダイアログでは、**AI でレビュー**がスクリプトで失敗やデータ損失の恐れがある箇所をアシスタントに確認させ、承認した読み取りで検証します。**AI で要約**は、承認依頼やチケット向けに変更内容を説明します。
- **データを比較の AI：** **差異を説明**は、件数と全差異にわたる典型的なずれから、差異の共通点と、タイムゾーン、丸め、同期の遅れなどの考えられる原因を説明します。**AI でフィルター**は、言葉での依頼を列ごとのフィルターと並び順に変換し、**キーを提案**は、主キーのないテーブルのキーを見つけます。AI が行の値を受け取ることはありません。
- **データを比較での並べ替えとフィルター：** 差異が数千件あっても、任意の列で並べ替え、各列の三点メニューからフィルター（等しい、異なる、より大きい、含む…）したり、列が変更された行だけを残したりできます。画面に表示されている行だけでなくすべての行が対象で、「すべて」はフィルターを通過した行だけにチェックを付けます。
- **`~/.ssh/config` からの SSH トンネル：** サーバーを手入力する代わりに、SSH 設定の `Host` をトンネルで使えます。DBine は OpenSSH が解決する内容（サーバー、ユーザー、キー、エージェント）を使用し、各サーバーが自分のユーザーとキーでサインインする `ProxyJump` チェーンや、正確なコマンドを確認した後にのみ実行される `ProxyCommand` にも対応します。接続前に経路が表示されます。
- **AI アシスタントのコンテキスト：** 各接続とデータベースに新しく追加された**コンテキスト**ノードには、そこでのすべてのチャットでアシスタントが受け取るメモ（ステータスコードの意味や指標の計算方法など）を保存でき、繰り返し説明する必要がなくなります。**設定 › AI アシスタント**には、すべての会話向けのテキストがあります。チャットでは使用中のものが表示され、その会話に限って 1 つをオフにできます。これらはアシスタントへの案内であり、許可されている操作は変わりません。
- **KDB+ のデータ同期とクローン：** **データを比較**は、2 つの kdb+ テーブル間で異なる行を見つけて修正します。各サーバーでハッシュを計算するため、変更された行だけが転送されます。また、移行では kdb+ プロセスを、テーブル、キー、型、属性、リンクされた列、関数、ビューごと別のプロセスにクローンできます。
- **スキーマとしての KDB+ 名前空間：** エクスプローラーは各名前空間の下にそのテーブル、ビュー、関数をまとめ、**新しいスキーマ…**と**スキーマを削除…**で名前空間を作成および削除でき、kdb+ への移行では元の各スキーマが名前空間として保持されます。
- **KDB+ のヘルスチェックとプロパティ：** ヘルスチェックはプロセス自体を読み取ります（`-w` 制限に対するメモリ、ガベージコレクション、インターンされたシンボル、遅いサブスクライバー、クエリのタイムアウトなし、パスワードのないポート、TLS）。**プロパティ**は、kdb+ が実行中の変更を許可する設定（`\g`、`\T`、`\P`、`\o`、`\z`、`\w`）を表示および変更します。
- **インデックスとしての KDB+ 属性：** `s#`、`u#`、`p#`、`g#` はテーブルの構造に表示され、テーブルデザイナー、比較、同期から設定および削除できます。スキーマ変換ではこれらをインデックスに変換し、元に戻せます。
- **KDB+ の名前変更：** **名前を変更…**は、テーブルと列に加えて、ビュー、関数、変数、名前空間でも使えます。

### 改善
- **スキーマを比較をステータスで絞り込み：** リスト上の各バッジ（異なる、左のみ、右のみ、同一）で、その行の表示と非表示を切り替えられるようになり、同一のものだけ、または片側にしかないものだけを確認できます。
- **KDB+ のノートブック書き込みと行数：** ノートブックの書き込みセルは、すべてのモード（挿入、キーによる更新、挿入または更新、置換）で kdb+ テーブルに書き込み、1 ステップで適用されるため、失敗してもテーブルは元のままです。また、エクスプローラーのドキュメントと移行は、スキャンせずに各テーブルの行数を取得します。

### 修正
- **組み込み SQLite のセキュリティ修正：** DBine 独自の SQLite（設定、および SQLite と libSQL ファイルに使用）を、CVE-2026-119375 を修正したバージョンに更新しました。
- **2 つのライブラリのセキュリティ修正：** DuckDB ドライバーの Arrow ライブラリと、DBine および DuckDB、SAP HANA、MySQL の各ドライバーが使用するシステムライブラリを、メモリ安全性の問題を修正したバージョンに更新しました（RUSTSEC-2026-0442、RUSTSEC-2026-0486）。
- **SQL Server の Windows サインイン（NTLM）：** 悪意のあるサーバーや傍受されたサーバーによって、DBine の NTLM 応答が自身の MIC フラグとサービス名を隠してしまう、または SQL Server ドライバーが数 GB のメモリを要求してしまう可能性がありました。DBine はこれらの長さを正しく書き込み、サーバーのオフセットを検証するようになりました。
- **エンジン間の同期スクリプト：** PostgreSQL から読み取った数値がテキストとしてスクリプトに入っていたため、型を保持する MongoDB などのエンジンでは `9` ではなく `"9"` が保存されたり、スクリプトが拒否されたりすることがありました。各値は、移行先の列が受け付ける形式で書き込まれるようになりました。
- **エンジン間でブール値を含むデータの比較：** PostgreSQL の `true` と `false` が他のエンジンのものと一致せず、ブール列を持つテーブルのすべての行が異なると表示され、同期スクリプトに移行先の列が受け付けない値が含まれることがありました。現在は本来の値として比較されます。
- **大きなテーブルでのデータの比較：** テーブルの行数が比較で読み取る行数（片側 200,000 行）を超える場合、両側が異なる行を読み取ることがあり、実際には存在する行が相手側にないと表示されたり、同期スクリプトがそれを削除または挿入したりすることがありました。両側がキー順で読み取られるようになり、部分的な比較では両側に存在する行のみが更新されます。
- **Databricks の大きな結果：** 結果が 25 MiB を超えるクエリは、先頭の行だけを表示する場合でも「Inline byte limit exceeded」で失敗していました。現在は要求した行を取得して部分的な結果として示し、エクスポートとグラフは結果全体を読み取ります。
- **Databricks の結果ダウンロード：** 結果の一部をダウンロードできなかった場合、一時的な資格情報を含むリンクがエラーに表示されていました。現在は表示されません。
- **SSH プロファイルの選択：** 接続の SSH トンネルタブで、プロファイルの一覧が空のボックスに縮んでいました。現在は行の幅いっぱいに表示され、接続が独自の設定を使用している場合はそのことが示されます。
- **スキーマを選択したときのスキーマを比較：** 全文検索カタログとストップリストが比較から消えなくなり、その差異が表示され、スクリプトはインデックスに必要なカタログを作成できます。
- **SQL Server の全文検索インデックスの同期：** 主キーの名前が異なるテーブルに移されたインデックスは、そのテーブルのキーを使用するようになり、その名前だけの差異は変更として表示されなくなりました。スキーマを比較で全文検索カタログまたはストップリストを削除すると、それを使用しているインデックスが一覧表示されます。
- **KDB+ への移行：** 再コピー（または中断したコピーの再開）のために kdb+ テーブルを空にしても、列、型、キーが保持され、列のない状態になりません。

## [1.4.2] - 2026-11-04

### 新機能
- **TLS 1.0/1.1 での古い SQL Server への接続:** サーバーが TLS 1.0 または 1.1 しか使えない場合でも、DBine は SQL Server 2012 以前に接続できます。常に最初に TLS 1.2 以降を試します。サーバーが古いプロトコルしか受け付けない場合は、DBine がサーバーのバージョンを示してお知らせし、そのまま接続するかどうかを一度だけ確認します。「はい」を選ぶと **SQL Server (TLS 1.0/1.1)** コンポーネントをダウンロードし、その接続について選択を記憶します。使用中は **レガシー TLS** のインジケーターが表示され、証明書は引き続き検証されます（または **サーバー証明書を信頼する** で固定できます）。このオプションは、接続の **SSL/TLS** タブでオフにできます。サーバーを TLS 1.2 にアップデートする（SQL Server 2012 SP4）ほうが、引き続きより安全です。

### 改善
- **エンジンのロゴ:** さらに 51 種類の接続タイプで、イニシャルの代わりに製品のロゴが表示されます。IBM Db2、Informix と Netezza、Vertica、Exasol、InterSystems IRIS、Microsoft Access、Greenplum、StarRocks、OceanBase、TDengine、Materialize、Memgraph、RisingWave、Dremio などです。

## [1.4.1] - 2026-11-03

### 新機能
- **自動アップデート:** DBine は起動時とその後 6 時間ごとに新しいバージョンを確認し、バックグラウンドでダウンロードして検証し、準備ができるとステータスバーに **再起動して更新** を表示します。そのまま終了した場合は終了時にアップデートがインストールされ、次回の起動から新しいバージョンになり、新機能の概要が表示されます。自力で更新できないインストール形式（deb、rpm、MSI、Flatpak）では、ダウンロードリンク付きの通知が引き続き表示されます。管理対象のマシンでは `DBINE_AUTO_UPDATE=0` で自動アップデートを無効にできます。
- **エディターの q:** KDB+ のクエリで q の構文ハイライトと、キーワード、組み込み関数、テーブル、列、関数、`.u.upd` のような名前空間付きの名前の補完が使えます。⌘/ で `/` を使って行をコメントアウトでき、q のスニペットも増えました。
- **KDB+ のスキーマ比較・同期・変換:** メモリ上のテーブルを比較・同期し（列の追加、削除、型変更、名前変更、キーの変更）、テーブル名を変更し、kdb+ と他のエンジン間でスキーマを変換できます。q の型とキー付きテーブルはプライマリキーに対応付けられます。パーティション化されたテーブルと splayed テーブルは、理由を示して拒否されます。

### 改善
- **KDB+ の外部キー、一括ロード、チャート:** 関連付けられた列は ER 図とキーによるジャンプ（**参照先の行へ移動**）で外部キーとして表示されます。インポートとマイグレーションは IPC 経由で型付きテーブルとして行を読み込み（10 万行を約 1 秒）、チャートは結果全体をサーバー側で集計します。
- **KX のロゴ:** KDB+ の接続に KX のロゴが表示されます。

## [1.4.0] - 2026-11-03

### 新機能
- **KDB+ に対応:** kdb+ プロセスに（平文または TLS で）接続して q で作業できます。各名前空間のテーブル、ビュー、関数、変数を参照し、q スクリプトを文ごとに実行し、グリッドでテーブルの行をフィルター、並べ替え、編集し、モニターでメモリと開いている接続を確認できます。kdb+ 3.6 以降では、読み取り専用の接続はサーバー側でも強制されます（`reval`）。古いサーバーでは、読み取り専用の接続はテーブルと変数しか開けません。「接続文字列をコピー」で q の `hopen` ハンドルと PyKX が得られます。
- **ブラウザーでの Databricks サインイン:** Databricks と Azure Databricks の接続では「ブラウザーでサインイン (SSO)」を使ってサインインできます。DBine がワークスペースのサインインページ（Azure では Microsoft Entra ID）を開くため、個人用アクセストークンやサービスプリンシパルなしで、組織の SSO と MFA が使えます。セッションは DBine を開いている間、自動的に更新されます。

### 改善
- **付与できる権限はサーバーから取得:** 「ユーザーと権限…」の権限一覧は、そのサーバーが付与できるものです。カタログを持つサーバーではそのカタログから（SQL Server の `sys.fn_builtin_permissions`、PostgreSQL の ACL、MySQL の `SHOW PRIVILEGES`、ClickHouse、Oracle、SAP HANA、Redis、MongoDB、Neo4j、Couchbase、OpenSearch など）、それ以外ではエンジンのドキュメントから取得するため、サーバーのバージョンに追従します。SQL Server では `VIEW DATABASE STATE`、`VIEW DATABASE PERFORMANCE STATE`、`SHOWPLAN` などが選べるようになりました。選んだ対象（データベース全体、スキーマ、テーブル、プロシージャなど）に当てはまるものだけが表示され、同じ一覧が「新しいスキーマ…」にも使われます。権限は引き続き手入力もできます。

### 修正
- **スプレッドシートのインポートをより安全に:** `.xls` と `.xlsb` ファイルの読み込みに calamine 0.38 を使うようになり、細工されたファイルで DBine がクラッシュしたりメモリを使い果たしたりすることはなくなりました（RUSTSEC-2026-0436）。
- **テキストフィールドは入力した内容をそのまま保持:** ユーザー名、パスワード、ホスト名、接続 URL、検索、フィルターなど、すべてのテキストフィールドで、OS による先頭の大文字化、自動修正、スペルチェックが行われなくなり、`demo_user` は `demo_user` のままです。Shift と Caps Lock はこれまでどおり動作します。スマートフォンアプリの接続フィルターも同様です。

## [1.3.1] - 2026-11-02

### 改善
- **ネットワーク切断後の接続の復旧：** 失敗した接続や接続中のまま止まった接続を、そのメニューから切断できるようになりました。切断するとセッションと SSH トンネルが閉じられ、再接続は最初からやり直します。接続が切れたために失敗したクエリは、そのセッションを破棄し、SSH トンネルがサーバーに到達できなくなっている場合はトンネルも破棄するため、次のクエリは自動的に再接続します。切断時には、タブに開いたトランザクションや実行中のステートメントがある場合に先に確認し、SSH トンネルの接続とサインインが無期限に待ち続けることもなくなりました。
- **オフラインで更新を確認できないときのメッセージを分かりやすく：** インターネットに接続していない場合、更新の確認やダウンロードで、ネットワークライブラリのエラーではなく、更新サーバーに到達できないことが表示されます。

### 修正
- **SSH トンネル、セキュリティ：** SSH ライブラリを更新し、複数のセキュリティ勧告に対応しました。最も重大なものは、SSH エージェントが保持する鍵が、エージェントの確認なしに署名できてしまう問題です。また、サーバーが細工したパケットで、トンネルを停止させたり、DBine に無制限のメモリを使わせたりすることもできなくなりました。

## [1.3.0] - 2026-10-30

### 新機能
- **SSH トンネルのプロファイル：** SSH トンネル（サーバー、踏み台サーバー、ユーザー、認証）を設定で一度プロファイルとして保存すれば、どの接続でも選択できます。各接続は独自のデータベースサーバーを保持します。プロファイルを編集すると、それを使用するすべての接続に次回の接続時に反映されます。接続の現在のトンネルをプロファイルとして保存することもでき、プロファイルのシークレットはシステムのキーチェーンに保存されます。
- **ホバーでテーブルの列を表示：** SQL エディターでテーブル名にポインターを合わせると、型、NULL 許可、主キー、各列のコメントとともに列が表示されます。すべてのエンジンで利用できます。

### 改善
- **Claude Code と Codex を使う AI アシスタント：** 同じ接続の別のデータベースについて質問すると、アシスタントはタブのデータベースを切り替えずにそのテーブルと列を読み取ります。これらのモデルがテーブルの行を受け取ることは、これまでどおりありません。

### 修正
- **Linux 上の SAP HANA、セキュリティ：** クエリをキャンセルしたときに、セッションが削除した後の信頼済み証明書のフォルダーを読み取らなくなりました。この瞬間を、同じコンピューターの別のユーザーが自分の認証局を仕込むために悪用できる可能性がありました。
- **セキュリティ、依存関係：** `ctutils` と `crypto-bigint` を、定数時間に関する修正を含むバージョンより新しいものに更新しました。
- **非常に長いテキストの Excel エクスポート：** Excel の上限を超える長さのセルに絵文字などの文字が含まれる場合、エクスポートが停止せず、再び収まるように切り詰められます。
- **Trino と Presto、セキュリティ：** 実在するどのスキーマよりも深くネストされた列の型を持つテーブルからデータをコピーまたはエクスポートしても、DBine がクラッシュしなくなりました。1.2.2 で追加された深さの上限が、この経路にも適用されます。

## [1.2.2] - 2026-10-28

### 修正
- **セキュリティ：ZIP 処理の重大な脆弱性を修正しました。** 10 月 28 日、DBine が ZIP ベースのファイル（Excel のインポートとエクスポート、AI アシスタント内蔵モデルのダウンロード）の読み書きに使用するライブラリ `zip` で、重大な脆弱性が公開されました（[GHSA-m665-v7pm-7grj](https://github.com/advisories/GHSA-m665-v7pm-7grj)）。細工されたアーカイブは、読み込み方法によって異なる内容を表示する可能性がありました。このバージョンでは DBine のすべての部分を修正済みのライブラリに切り替えています。1.2.1 の数時間後にリリースされるのはこのためだけですので、アップデートをおすすめします。
- **Trino と Presto、セキュリティ：** 実在するどのスキーマよりも深くネストされた列の型（悪意のあるサーバーが送信する可能性があります）は、階層ごとに解析せず、届いたとおりに表示されるようになり、DBine がクラッシュすることはなくなりました。

## [1.2.1] - 2026-10-28

### 修正
- **列の補完が、書いているクエリに追従します:** エディターには、カーソル位置のステートメントが読むテーブル、CTE、サブクエリの列だけが表示され、ファイル内の他のステートメントの列は表示されません。2 つのテーブルに共通する列はテーブルごとに 1 回ずつ表示され、エイリアスがラベルとして付き、修飾された形（`c.customer_id`）で挿入されます。CTE や派生テーブルの列は、クエリ内とそのエイリアスの後で表示されます。
- **行と struct のフィールド名:** Trino と Presto の `ROW` 値、PostgreSQL の複合型、Arrow Flight SQL の struct で、各フィールドが名前付きの JSON として表示されます。入れ子の行、行の配列、値が行であるマップでも同様です（`[[42,[["demo-product",2]],null]]` ではなく `[{"customer_id":42,"items":[{"product_name":"demo-product","quantity":2}],"note":null}]`）。`null`、空文字列、空配列は区別されたままです。ClickHouse の名前付きタプルは宣言どおりのフィールド順を保ちます。
- **VIEW DEFINITION のない SQL Server ログインでの移行:** 移行元のログインがテーブルを読めても定義を読めない場合（Azure SQL でよくあります）、移行スクリプトが `CHECK ()` を書き出して「Incorrect syntax near ')'」で失敗し、列の既定値も通知なしに破棄されていました。今後は、これらの CHECK、既定値、計算式はスクリプトから除外され、プレビューと実行レポートの先頭に、理由と DBine が読み取れるようにする `GRANT VIEW DEFINITION` とともに 1 件ずつ一覧表示されます。生成されたスクリプトとスキーマ同期でも通知され、移行元が自身の CHECK を読めなかったことを理由に、同期が移行先の CHECK を削除することもなくなりました。空の CHECK や DEFAULT を書き出すエンジンはなくなりました。

### 修正

- **SQL Server Management Studio からのインポート:** 登録済みサーバーに加えて、SSMS の接続ダイアログが記憶しているサーバー（接続履歴）も、ログイン、データベース、暗号化の設定とともにインポートされます。SSMS 18 から 20、および SSMS 21 以降の新しいフォルダーに対応します。macOS と Linux では、ファイルダイアログで `RegSrvr.xml`、`UserSettings.xml`、`.regsrvr` ファイル（および DataGrip の `dataSources.xml`）を選べるようになりました。以前は JSON ファイルしか選べませんでした。

- **マップ表示:** ジオメトリ列(PostGIS、MySQL、SQL Server、SQLite/SpatiaLite、DuckDB、MongoDB、Elasticsearch など)または緯度・経度の列を含む結果を、内蔵のオフライン世界地図の上に、このマシン上で描画するマップで表示できます。詳細なオンライン地図タイルは **設定 › マップ** で有効にできます。その場合、プロバイダーには閲覧中の範囲が伝わりますが、データは伝わりません。
- **マップで Oracle に対応:** SDO_GEOMETRY 列が、テーブルのデータでも独自のクエリでも結果のマップに表示されるようになりました(サーバー側で SRID とともに WKT に変換)。これらのセルはグリッドでは読み取り専用です。
- **データファイルを直接開く:** SQLite、DuckDB、CSV、TSV、Parquet、JSON、Excel ファイルを、ダブルクリックや「DBine で開く」、ウィンドウへのドロップ、**ファイル › ファイルを開く…**(Cmd/Ctrl+O)で開けます。それぞれ一時的な接続として開き、**接続を保存** で保持できます。データファイルは先頭の 1,000 行がすぐに表示されます。
- **コマンドパレット:** Cmd/Ctrl+Shift+P であらゆる操作を検索して実行でき、現在のエンジンが対応するものだけが表示されます。**移動…**(Cmd/Ctrl+P)では、接続、データベース、テーブル、ビュー、ルーチン、保存したクエリ、開いているタブに移動できます。パレットのどの操作にも独自のショートカットを割り当てられます。
- **関連する行へ移動:** テーブルのデータやクエリの結果で、**参照先の行へ移動**(または Cmd/Ctrl+クリック)を選ぶと、その外部キーで絞り込んだ親テーブルが開きます。**これを参照している行** では、その値で絞り込んだ各子テーブルが開きます(複合キーにも対応)。外部キーがあるすべてのエンジンで使えます。
- **SQL ノートブック:** **ファイル › 新しいノートブック** でノートブックを開きます。任意の接続で実行できる SQL セルがそれぞれ結果とグラフを下に保持し、説明用のテキストセルも使えます。標準の Jupyter `.ipynb` として保存され、GitHub、VS Code、Jupyter で表示でき、Azure Data Studio や Jupyter の `%%sql` ノートブックでも開けます。ファイルには各結果のプレビュー(セルあたり 100 行と 1 MB、**設定 › ノートブック** で変更可)が総行数、時間、所要時間とともに保存され、接続の詳細やパスワードは保存されません。プロジェクト内では、有効にしない限りノートブックは結果なしで保存されます。アシスタントは、行を見ることなく、結果の説明、次のセルの提案、大きなクエリをグループ化したバージョンの提案ができます。HTML または Markdown にエクスポートできます。
- **結果全体を対象にしたグラフ:** グラフは、グリッドに読み込まれた行だけでなく、結果のすべての行を対象に計算されます。SQL エンジンではグループ化をサーバーで実行し、ノートブックの DataFrame SQL セルでは DuckDB が、その他のエンジンでは DBine が行います。
- **グラフの種類を追加:** ヒストグラム、ヒートマップ、箱ひげ図(ひげと外れ値付き)、棒と折れ線の組み合わせ、KPI(結果全体の合計)。
- **ノートブックのセルに複数のグラフ:** ノートブックのセルは、結果に対して複数のグラフを表示でき、マップが使うデータソースも記憶します。
- **ノートブックのエクスポートにグラフを含める:** HTML または Markdown にエクスポートしたノートブックに、グラフが画像として含まれます。
- **ノートブックで異なるデータベースの結果を結合:** 各セルの結果は、セルの名前(ヘッダーに表示され、編集できます)を持つ DataFrame になります。**DataFrame SQL** セルは、接続なしで、上にある DataFrame をテーブルとして DuckDB の SQL で照会・結合できるため、1 つのセルで PostgreSQL の結果と SQL Server や MongoDB の結果を結合できます。ファイルの書き込みやネットワークへのアクセスができないメモリ上の DuckDB データベースで実行され、ノートブックを閉じると破棄されます。各ソースの行は、このセッションでの実行結果、またはそのソース自身の接続で読み取り専用として再実行したクエリから取得されます(DataFrame あたり最大 1,000,000 行、**設定 › ノートブック** で変更可)。
- **スケジュール実行のレポートとしてのノートブック:** スケジュールタスクは、DBine を閉じたままノートブックを実行し(**ノートブックを実行**)、実行済みのコピーを保存して HTML または Markdown にエクスポートできます。次の **メールを送信** ステップで、それを添付するか、HTML エクスポートをメール本文として送信できます。無人実行中に確認を求めることはありません。読み取るのはそのノートブックで **常に許可** にしたファイルのみで、確認が必要な環境ではステップが明示的に許可した場合にのみ実行され、データを変更するセルはタスクの承認に含まれます。スケジュールされたエクスポートにはテーブルが含まれ、グラフはアプリからエクスポートするときに含まれます。
- **DataFrame SQL セルでローカルファイルを読み込み:** DataFrame SQL セルは、お使いのコンピューター上の CSV、Parquet、JSON、NDJSON、Excel ファイルを `read_csv`、`read_parquet`、`read_json`、`read_xlsx` で読み込めます(`data/*.csv` のようなパターンやファイルのリストにも対応)。地理ファイル(GeoJSON、付属ファイルを含む Shapefile、GeoPackage、KML、GPX、FlatGeobuf)は `st_read`、SQLite と DuckDB のデータベースファイルのテーブルは `sqlite_scan` と `read_duckdb` で読み込めます。いずれも DataFrame となり、どのエンジンのセルの結果とも結合できます。ジオメトリは `ST_Contains` などの空間関数でも引き続き使え、マップにも表示されます。ファイルは読み取るだけで、書き込むことはありません。ファイルを初めて読み込む前に、ノートブックが確認します。今回の実行のみ許可、このコンピューターでこのノートブックに常に許可(パターンは新しいファイルにも適用)、または拒否から選べます。資格情報、鍵、シェル履歴、システムファイルは読み込まれません。前回の実行からファイルの内容が変わっている場合は、結果にその旨が表示されます。設定 › ノートブックには各ノートブックが読み取れるファイルが一覧表示され、削除もできます。同じリーダーで、Web 上(`https://`)や Amazon S3、Google Cloud Storage、Azure Blob Storage(`s3://`、`gs://`、`az://`、`abfss://`、`s3://bucket/2026/*.parquet` のようなパターンも可)のファイルも読み込めます。承認は同じで、最初にサーバーが表示されます。DBine がファイルを自分でダウンロードして、読み込み後に削除される非公開の一時フォルダーに保存し、このコンピューターの AWS、Google Cloud、Azure のサインインを使います(AWS プロファイルは設定 › ノートブックで選択可)。ローカルやプライベートネットワークのアドレスには接続せず、他のサーバーへのリダイレクトにも従わず、URL に含まれた資格情報も受け付けません。他のプログラムで開いている GeoPackage には、`-wal` に残っている変更も含まれるようになりました。
- **ノートブックを Python ノートブックとしてエクスポート:** **エクスポート › Python ノートブック(.ipynb)** は、元のノートブックを再現する Jupyter ノートブックを書き出します。接続ごとに SQLAlchemy エンジン(または pymongo や redis など、エンジン固有の Python クライアント)が作られ、各クエリセルはセルの名前の pandas DataFrame に読み込まれ、DataFrame SQL セルはそれらの DataFrame 上で DuckDB により実行され、テキストセルは Markdown になります。パスワードとトークンはエクスポートされません。コードは環境変数から読み込み、最初のセルにその一覧とインストールするパッケージが記載されます。プレビューを含めるよう選ばない限り、結果は含まれません。
- **ノートブックから DataFrame をテーブルに書き込み:** **書き込みセル**(任意のセルの下に **テーブルに書き込み…** で追加)は、セルの結果全体を SQL Server、PostgreSQL、MySQL、MariaDB、Oracle、SQLite、DuckDB、MongoDB などのテーブルに書き込みます。挿入、キーによる更新、挿入または更新、テーブルの内容の置き換えが選べ、カラムのマッピングやプレビューがあり、必要なら新しいテーブルも作成できます。書き込みは毎回事前に確認し、書き込み先、方法、行数を表示します(本番の接続ではテーブル名の入力が必要)。トランザクションに対応するエンジンでは 1 つのトランザクションで実行され、読み取り専用の接続には書き込みません。スケジュールタスクでは、ステップがそのセル、テーブル、モードを許可している場合にのみ書き込みセルが実行されます。
- **ノートブックのパラメーター:** ノートブックでは、パラメーター(テキスト、数値、日付、日時、ブール値、固定リスト。既定値付き)を定義し、セルから `{{name}}` として使えます。実行時に不足している値を尋ね、各値はデータとしてデータベースに渡され(ドライバーによるバインド、またはエンジン自身の規則によるクォート)、各結果にはそれを生成した値が表示されます。
- **さらに 5 つの言語:** DBine とそのスマートフォンアプリが、スペイン語、英語、ポルトガル語、フランス語、イタリア語に加えて、ドイツ語、ロシア語、簡体字中国語、日本語、韓国語に対応しました。言語はシステムの言語に従い、使用中の言語だけが読み込まれます。

### 改善
- **macOS で署名済み:** macOS 版アプリは Apple Developer ID で署名され、Apple による公証を受けているため、「開発元を検証できません」という警告やターミナルのコマンドなしで開けます。署名済みバージョンを初めて開くと、DBine がキーチェーンの鍵を使用してよいか macOS が一度だけ尋ねます。**常に許可** を選んでください。
- **クラウドサインインはインスタンスの証明書のみを信頼:** AWS IAM、Google Cloud IAM、Microsoft Entra でサインインする接続と、インスタンスの CA ファイルを使う Cloud SQL および AlloyDB の接続は、トークンやパスワードを送信する前に、任意の公開証明書ではなく、その CA(または Amazon の RDS バンドル)のみを受け入れるようになりました。**サーバー証明書を信頼する** がオンの状態でパスワードを平文で要求するサーバーは、パスワードを受け取らず、接続に失敗します。
- **Windows で署名済み:** Windows のインストーラーとアプリはコード署名証明書で署名されているため、Windows には「不明な発行元」ではなく DBine の発行元が表示されます。
