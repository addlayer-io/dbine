# Static function catalog (see functions::parse_catalog). Filled per engine from its documentation.
# The SQL standard's functions (ISO/IEC 9075-2, SQL:2003 to SQL:2023): the
# base an engine reached through ODBC or Flight SQL gets when it has no
# catalog of its own. The ODBC scalar functions (LOCATE, SOUNDEX…) are not
# here: they come from what the driver says it supports (SQLGetInfo,
# GetSqlInfo). An escape-only one (UCASE, IFNULL, DAYOFWEEK…) works only
# inside `{fn …}`, so the bare call the editor inserts fails on engines
# without that native name.
