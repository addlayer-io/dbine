# SQL Server's built-in functions (Microsoft Learn, "What are the SQL database
# functions?"), as T-SQL writes them. Versions are SQL Server's major ones:
# 10 = 2008, 10.50 = 2008 R2, 11 = 2012, 13 = 2016, 14 = 2017, 15 = 2019,
# 16 = 2022, 17 = 2025. The niladic ones written without parentheses
# (CURRENT_TIMESTAMP, CURRENT_DATE, CURRENT_USER, SESSION_USER,
# SYSTEM_USER, USER) are left out: the editor inserts an entry as a call,
# `name()`, which T-SQL refuses for them; the SQL keywords complete them
# as written. See functions::parse_catalog for the format.
