# ksqlDB: the built-in functions of Confluent Platform 7.7.1 (ksqlDB 0.29),
# from the server's own DESCRIBE FUNCTION: one line per argument list, the
# result type when every overload with that list agrees (T, S… are
# generic). The server's SHOW FUNCTIONS is the source; this catalog gives
# its entries their arguments and stands in when it can't be read. Without
# the test UDFs Confluent's image carries (see `FIXTURES` in
# functions.rs). Not filtered by version: SHOW FUNCTIONS answers on every
# ksqlDB release, so this is only read when the server can't be reached.
