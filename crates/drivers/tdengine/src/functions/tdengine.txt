# TDengine 3.x: the built-in functions of the SQL reference ("Functions"),
# with the versions the reference gives (since= is the first release that
# has it). Where the reference gives none, since= is the first release tag
# whose source/libs/function/src/builtins.c registers it (MD5, CRC32,
# TO_BASE64). Pseudocolumns (_wstart, _irowts…) aren't functions and aren't
# here. The user's UDFs come from information_schema.ins_functions.
