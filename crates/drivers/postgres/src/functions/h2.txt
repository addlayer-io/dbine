# H2's built-in functions (see dbine_driver::functions::parse_catalog), from
# h2database.com/html/functions.html, functions-aggregate.html and
# functions-window.html (H2 2.x, which DBine reaches through its PostgreSQL
# server). H2 lists only the user's routines (INFORMATION_SCHEMA.ROUTINES),
# so the built-ins come from here. Names are case-insensitive.
