# Amazon Redshift's SQL functions (see dbine_driver::functions::parse_catalog),
# from docs.aws.amazon.com/redshift/latest/dg/c_SQL_functions.html. Redshift's
# pg_proc keeps PostgreSQL 8.0's functions, most of which the compute nodes
# don't run, so the built-ins come from here; the user's functions from
# pg_proc_info. Leader-node-only functions are left out.
