# which is what redis.io publishes), plus the hash commands of Redis 8.0.

# are filtered by the Redis version they report (`redis_version`).
# Container commands list each subcommand as CONTAINER|SUBCOMMAND (the
# server's own spelling), shown as `CONTAINER SUBCOMMAND`.
# Commands Redis marks internal (replication, cluster and debug plumbing)
# are left out.
