# Open Distro for Elasticsearch SQL: the functions its SQL reference
# documents (docs/user/dql/functions.rst, window.rst and
# beyond/fulltext.rst of opendistro-for-elasticsearch/sql, up to its last
# release, 1.13.2.1), plus MODULUS (see its line). `since=` is the first
# plugin release whose reference lists the function (the plugin's own
# version, as `_cat/plugins` gives it, not Elasticsearch's). The plugin has
# no SHOW FUNCTIONS. CASE is syntax, not a call, and is left out.
