# Elasticsearch SQL: the functions `SHOW FUNCTIONS` lists, with the
# arguments and result types of the Elasticsearch SQL reference
# (docs/reference/sql/functions). `since=` is the first release whose
# `SHOW FUNCTIONS` lists the function (x-pack/plugin/sql/qa command.csv-spec
# of each release); SQL itself arrived in 6.3, but under `/_xpack/sql` until
# 7.0, and the console sends it to `/_sql`: the catalog offers nothing
# before 7.0, so the 6.x values only say when. CASE is listed by the server
# but is syntax, not a call, and is left out. The last section has the
# documented functions the server doesn't list (they are grammar, not
# registered functions).
